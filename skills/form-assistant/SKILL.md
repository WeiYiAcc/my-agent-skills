# 表单填写助手

根据用户提供的信息，按照以下规则进行计算和填写核实情况模板。

**首先确认当前时间，并告知用户。**

## 数据查询

填表前如需查询已有记录，可用 `ariadne-work` graph：

```bash
# ariadne-work graph 查询（路径已迁移，以实际路径为准）

# 查某户的产业奖补记录
bb my-work-query '[:find ?title :where [?e :block/title ?title] [?e :user.property/申请户主姓名 ?n] [?n :block/title "姓名"]]'

# 查某户的预警核实记录
bb my-work-query '[:find (pull ?e [*]) :where [?e :block/tags ?t] [?t :block/title "预警核实"] [?e :user.property/户主姓名 ?n] [?n :block/title "姓名"]]'

# 查某村的产业奖补统计
bb my-work-query '[:find ?title :where [?e :block/tags ?t] [?t :block/title "产业奖补"] [?e :user.property/村 ?v] [?v :block/title "村名"] [?e :block/title ?title]]'
```

## 检查限制

### 1. 家庭情况规则

- 脱贫年度字段有数据的，就是脱贫户
- A类低保一般为完全丧失劳动能力或重残无业人员
- 完全丧失劳动能力或重残无业人员对应无劳动力
- 弱劳动力需要提醒用户是否有疾病
- 根据身份证计算年龄：凡于当年8月31日前年满6周岁的儿童必须入学（小学），8月31日后出生的下一年9月1日开始上学；满7周岁上小学，满13岁上初中，学生在12岁时进入初中从七年级开始，通常在九年级（初三）时年满15岁。年龄与年级有疑问时询问用户核实实际情况
- 研究生以下在校生属于无劳动力，填写义务教育
- 技校免除学杂费，九年义务教育也免除学杂费
- 有在校生的，填写"该户义务教育在校生人数为x人"或"该户非义务教育在校生人数为x人"
- 无劳动能力的，没有务工和务农收入
- 70周岁及以上老人一律填写"无劳动力"（不能填弱劳动力）；60-69周岁视健康状况填弱劳动力或无劳动力
- 有劳动能力之类的词汇，必须写成模板的专业术语"普通劳动力"
- 一般户或脱贫户两者互斥，保留一个（脱贫户（√）or 一般户（√）），留空要提醒用户，不要默认填写

### 2. 其他情况说明规则

- 值为"无""否""未"的子项目删除，**但⑥（商品房/商铺/小车）除外——无论有无必须明确填写**
- 空白子项目删除
- 删除后重新排序编号
- 有内容的子项目用分号换行连接

### 3. 收入情况规则

- 子项目冒号后面填写情况，分号换行
- 没有备注或数据的子项目删除，重新排序
- 如"1.工资性收入：无"不要出现，直接删除该行
- 年总收入按实际月份计算（例：现在是2025年01月，低保开始享受时间为2025年12月，215元/人/月，实际享受2月，年合计430元=215×1×2）
- 政策性收入无则删除该项目
- 生产经营性收入无则删除该项目
- 生产经营性支出无则删除该项目
- 非义务教育阶段有学费，学费是合规支出
- 家庭纯收入和家庭年人均纯收入计算只能扣除生产经营性支出，不能扣除合规自付支出以及非义务教育在校生费用支出
- 任何计算过程不填入模板，删除计算过程，只填写最终结果
- 支出收入为0的删除（如"1.工资性收入：无"该行删除）

### 4. 收入支出合理性校验规则

填写完成后，必须对以下项目进行合理性检查，发现异常时在第三步提醒用户：

#### 4.1 生产经营性支出下限检查
- 种植类支出（不含人工）参考下限：种子 50 + 化肥 150 + 农药 50 = **250元/亩/批**
- 若用户提供的支出低于 250元/亩/批，提醒用户核实是否遗漏种子、化肥、农药等成本
- 养殖类支出参考当地饲料、兽药等成本

#### 4.2 主要作物收入参考范围（广西地区）
| 作物 | 亩产（公斤） | 批发单价（元/斤） | 每亩每批参考收入（元） | 批次/年 |
|------|:---:|:---:|:---:|:---:|
| 普通玉米（干粒） | 350-450 | 1.1-1.3 | 600-800 | 2 |
| 甜糯玉米（鲜食） | 850-1000 | 0.69-1.0 | 1000-2000 | 2 |
| 水稻 | 400-500 | 1.3-1.5 | 700-1000 | 2 |
| 甘蔗 | 4000-6000 | 0.05-0.06 | 400-720 | 1 |
| 花生（干货） | 200-300 | 2.8-3.5 | 1000-1500 | 1 |
| 桑蚕（鲜茧） | 14-20公斤/亩/批（蚕茧） | 50-65元/公斤 | 700-1300 | 3-5 |

> 花生数据来源：一亩田2026年广西产地报价3.09元/斤；广西农科院普通品种亩产200-300公斤（干货）；弱劳动力户保守参考：**每亩约1000元**（下限）。
> 桑蚕数据来源：广西户均5亩桑蚕约2.8万元/年（凤山2024数据）；鲜茧价格50-65元/公斤（2024-2025年环江、那坡均价）；单人普通劳动力保守取4批×700元/亩 = 14000元/年（5亩）；支出（蚕种+蚕药）约80元/亩/批。

## 广西残疾人两项补贴标准（2025年1月起）

> 依据：桂民发〔2025〕25号（2025年8月21日发布，追溯自2025年1月1日起执行）

| 补贴项目 | 标准 | 适用对象 |
|---|:---:|---|
| 困难残疾人生活补贴 | **90元/月** | 享受低保的残疾人（不分等级） |
| 重度残疾人护理补贴 | **90元/月** | 一级、二级重度残疾人（不分等级） |

> 两项补贴统一从80元/月提高至90元/月，不再按残疾等级区分金额。
> 三级、四级残疾人无护理补贴（仅一二级重度残疾享受）。
> 困难残疾人生活补贴要求：持有残疾证 + 享受低保。

> 甜糯玉米数据来源：广西农业农村厅品种数据 + 惠农网2025-2026年广西产地报价（批发）。
> 弱劳动力户保守参考：亩产600-700公斤，批发0.7元/斤，**每亩每批约800元**（下限）。

**甜糯玉米生产支出参考（不含人工，每亩每批）：**

| 项目 | 参考金额 |
|---|---|
| 种子 | 60-80 元 |
| 化肥 | 150-200 元 |
| 农药 | 50-70 元 |
| **合计** | **260-350 元**（下限取 250 元） |

- 若用户提供的收入明显超出参考范围，提醒用户核实产量和售价
- 参考范围仅供校验，以用户核实后的实际数据为准

#### 4.3 临时救助资格核查

填写完成后，若存在以下情形，须提醒用户核查是否符合广西临时救助条件（详见 facts：`广西临时救助政策（桂民规〔2024〕8号）`）：

| 情形 | 建议类型 |
|---|---|
| 家庭成员**近期突发重大疾病**（癌症、重大手术等） | 优先申请**急难型** |
| 年度医疗合规自付支出较大，减合规后人均纯收入明显下降或接近预警线 | 申请**支出型** |
| 两种情形并存（如癌症持续治疗） | **急难型+支出型**均可申请 |

#### 4.4 表述规范化
- 种植收入单价必须写明「每亩每批收入X元」，不得简写为「每批收入X元」（避免歧义：每批总收入 vs 每亩每批单价）
- 格式示例：种植甜糯玉米3亩，一年两批，每亩每批收入1000元，年收入合计6000元

```

## 文件输出规则

填写完成后，如需生成 md / docx 文件，按以下规则命名和生成：

**文件名格式（denote-like）**：
```
{timestamp}--{户主姓名}-核实情况__{当前年份}年_走访核实.{ext}
```
- `timestamp`：执行时 `date +"%Y%m%dT%H%M%S"` 取当前时间
- `当前年份`：执行时 `date +"%Y"` 取当前年份（非收入数据年份）
- 示例：`20260324T170352--梁立陆-核实情况__2026年_走访核实.md`

**输出目录**：`~/ghq/github.com/WeiYiAcc/ariadne-fact/work/走访核实/`

**生成命令**：
```bash
# 1. 写入 md（内容为填写好的模板）
# 2. 用 pandoc 转换为 docx
pandoc {md路径} -o {docx路径} --standalone

# 3. 同步到 Windows 用户目录（动态解析，勿写死路径）
WIN_HOME=$(wslpath "$(cmd.exe /c 'echo %USERPROFILE%' 2>/dev/null | tr -d '\r')")
WIN_DIR="$WIN_HOME/走访核实"
mkdir -p "$WIN_DIR"
cp ~/ghq/github.com/WeiYiAcc/ariadne-fact/work/走访核实/{文件名}.md "$WIN_DIR/"
cp ~/ghq/github.com/WeiYiAcc/ariadne-fact/work/走访核实/{文件名}.docx "$WIN_DIR/"
```

> `WIN_HOME` 动态取自 Windows 环境变量 `%USERPROFILE%`，通过 `wslpath` 转为 WSL 路径，无需写死用户名或盘符。
