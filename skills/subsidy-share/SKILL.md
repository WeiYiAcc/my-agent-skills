# 产业奖补材料分享规范

## 核心原则

**正交**：压缩包内的文件夹结构和汇总表格必须正交——表格里每一行都能在文件夹里找到对应材料，文件夹里每一户都在表格里有记录，不多不少。

## 压缩包结构

```
{批次}相关表格.zip
├── {批次}预拨付表.xlsx          ← 汇总表（唯一真相）
├── 注意事项.docx               ← 必须有：户号重复、特殊情况说明
├── 参考文档/                   ← 来源数据（验收反馈表等）
├── 已验收未拨付/               ← 材料齐全，可拨付
│   └── 未拨付_户号-xxx_屯-xxx_户主-xxx/
│       ├── 1_xxx-附件5 ...申请表_打印用.docx
│       ├── 2_xxx_身份证一卡通_打印用.docx
│       └── 3_xxx_验收图_打印用.docx
├── 待验收_缺验收图/            ← 反馈表有但缺图
│   └── 未拨付_户号-xxx_屯-xxx_户主-xxx/
└── 新申报/                    ← 新提交，未参加验收
    └── 未拨付_户号-xxx_屯-xxx_户主-xxx/
```

## 文件命名规范

### 户文件夹
```
未拨付_户号-{13位}_屯-{屯名}_户主-{姓名}_验收批次-{5.19|5.20|5.21新|待定}_帮扶人-{姓名}
```

### 户内文件（按打印顺序编号）
```
1_{户主}-附件5 产业以奖代补项目验收申请表_打印用.docx
2_{户主}_身份证一卡通_打印用.docx
3_{屯}_{户主}户_{品种}_验收图_打印用.docx
```

## 汇总表字段

| 字段 | 说明 | 格式 |
|------|------|------|
| 序号 | 每行唯一递增 | 数字 |
| 乡镇 | 里高镇 | 固定 |
| 村 | 三合村 | 固定 |
| 屯 | 自然屯名 | 文本 |
| 户号 | 13位 | 文本（防截断） |
| 申请户主姓名 | | 文本 |
| 身份证号码 | 18位 | 文本（防截断） |
| 脱贫年度 | 如"2018年脱贫户" | 文本 |
| 属性 | 脱贫户/退出户/监测对象 | 文本 |
| 联系电话 | 11位 | 文本（防截断） |
| 品种 | 产业名称 | 文本 |
| 奖补规模数 | 亩/头/只 | 数字 |
| 奖补金额（元） | | 数字 |
| 验收状态 | 已验收/待验收（缺验收图）/待验收（新申报） | 文本 |
| 拨付状态 | 待拨付（材料齐全）/待拨付（缺验收图）/待拨付（待验收） | 文本 |
| 来源 | 5.19验收反馈表/5.20验收反馈表/5.21新验收反馈表/新申报 | 文本 |

## 注意事项.docx 必写内容

1. **户号重复说明** — 同一户号不同申请人的情况，明确"已拨付不得重复"
2. **分类说明** — 各文件夹的含义和处理建议
3. **数据来源** — 表格数据从哪里来的

## 正交校验

分享前必须验证：

```python
assert set(zip里的户主) == set(xlsx里的户主)  # 文件夹和表格一一对应
assert len(xlsx序号) == len(set(xlsx序号))     # 序号唯一
```

校验不通过不分享。

## CSV 格式（内部使用）

- 标准 RFC 4180（所有字段双引号包裹）
- 编码 UTF-8 BOM（`utf-8-sig`）
- VSCode + Rainbow CSV / Edit CSV 编辑
- Excel 打开长数字会截断 → 需要时用 xlsx

## 匹配规则（防止同名误匹配）

- **户号精确匹配**（最可靠）
- **姓名+屯联合匹配**（反馈表无户号时用）
- **禁止纯姓名匹配**（韦桂花、韦云锋等有同名不同人）

## 生成命令

```bash
# 预拨付表
PYTHONPATH=components:bases uv run python -m subsidy.photos extract  # 验收图OCR
uv run doit extract_验收图                                           # 同上（doit）

# 打包分享
# 在 session 里让 AI 执行：
# 1. 生成/更新预拨付表 xlsx+csv+jsonl
# 2. 正交校验
# 3. 生成注意事项.docx
# 4. zip 打包（docx/pdf only，不含 jsonl）
```
